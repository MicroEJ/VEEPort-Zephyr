# Crypto Test Suite

This folder contains a ready-to-use project for testing Crypto implementations on a device.
This Test Suite will typically test signature algorithms implementation, certificate creation, random data generation...

## Specifications

- Tested Foundation Library: [Crypto](https://repository.microej.com/modules/ej/api/crypto/)
- Test Suite Module: [com.microej.pack.crypto#crypto-testsuite](https://repository.microej.com/modules/com/microej/pack/crypto/crypto-testsuite)

Update the Crypto Test Suite module version in the [build.gradle.kts](build.gradle.kts) to match the requirement of the tested VEE Port.

Please refer to [VEE Port Qualification Test Suite Versioning](https://docs.microej.com/en/latest/VEEPortingGuide/veePortQualification.html#test-suite-versioning)
to determine the Crypto Test Suite module version.
